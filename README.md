# Чёрная дыра

Браузерная игра на одного: управляй чёрной дырой, поглощай процедурный город и расти. Сначала пролезают люди,
урны и фонари, потом машины, дома, многоэтажки и небоскрёбы. Раунд две минуты, звёзды за долю съеденного города.

Физика Rapier (WASM), графика three.js, без бандлера и сервера. Контекст и устройство: [`HANDOFF.md`](HANDOFF.md).

## Запуск

```bash
pnpm install
pnpm dev             # http://localhost:3000, ?bot — автопилот
pnpm test            # город, рост, провал, раунд ботом — под Node
pnpm build           # dist/ для сайта
pnpm vendor          # после обновления three или Rapier: скопировать их в public/vendor/
```

## Управление

- Мышь или палец: зажми и тяни, дыра едет в сторону отклонения (экранный джойстик).
- Клавиатура: WASD или стрелки, пробел — начать.
