# Handoff

Проект начат 2026-09-26: браузерная игра на одного для usertrv.dev (портфолио), в духе Hole.io. Отвечай по-русски.
Репозиторий `userTrv/black-hole` (приватный), работа только через PR в `main`.

## Как пришли к идее

Кирилл хотел зрелищную игру на одного на одном устройстве. Отвергнуты: пульт с телефона, рыбалка
(такая уже есть), подрывник `userTrv/demolition` (скучно, мало зарядов — репо оставлен архивом,
оттуда взяты dev-сервер, сборка, vendor и звук).

## Устройство

- `public/game/city.js` — город по сиду: сетка 6×6 кварталов (жилые, деловые, торговые, парки, парковки),
  улицы с разметкой, фонари, урны, гидранты; машины и автобусы едут по полосам, люди — по тротуарам.
- `public/game/growth.js` — радиус от съеденной площади, что пролезает (узкая сторона < 0,92 диаметра),
  звёзды (20/40/60 % города по очкам).
- `public/game/world.js` — мир. Предметы без тел, пока далеко; рядом с дырой получают тело Rapier.
  Пролезающий предмет центром над дырой перестаёт касаться земли (хук `filterContactPair`; в Rapier JS
  хуки работают только вместе с `EventQueue`!), у края дыры трение пропадает (правило Min) и его тянет внутрь.
  Ниже дна — съеден. Люди бегут от дыры вдоль тротуара.
- `public/game/bot.js` — бот: калибровка роста, тест раунда, фон меню, `?bot`.
- `public/render/view.js` — земля одной текстурой-картой, предметы через InstancedMesh (≈75 вызовов отрисовки),
  дыра через трафарет (земля не рисуется в круге, стенки ямы — только в нём), фасады окон шейдером по размеру
  экземпляра, сетчатое просвечивание зданий между камерой и дырой.
- `public/main.js` — меню, раунд 2 минуты, джойстик и клавиши, тосты «Машины!/Дома!/Небоскрёбы!», итог, рекорд
  в `localStorage['black-hole-best']`. `window.blackHole = { game, view }` для отладки.

## Калибровка

Бот за 120 с доходит до максимального радиуса (16 м) к ~100 с и съедает ~35 % города (2 звезды).

3. Звук ярче, эффекты на крупных «глотках» (вспышка, замедление), счётчик комбо.
4. Выкладка на сайт: репо сделать публичным, карточка в `presentation-site` (projects.json, projects.ts, обложка).
