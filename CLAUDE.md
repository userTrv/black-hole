# Чёрная дыра

Контекст проекта и следующие шаги: `HANDOFF.md`. Запуск: `README.md`.

- Проверка: `pnpm test`; вживую: `pnpm dev` и открыть http://localhost:3000 (`?bot` — автопилот). Пакетный менеджер pnpm.
- Без сборки и фреймворков, ES-модули в `public/`, только относительные пути (игра будет жить под префиксом).
- Тексты интерфейса и комментарии по-русски.
- Работа только через PR в `main`, мержит Кирилл.
- На сервере (VDS с VPN) ничего не делать без явного разрешения Кирилла.
